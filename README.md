# КодСкан — Правила сканирования

Правила безопасности для бесплатного браузерного сканера [КодСкан](https://kodscan.ru). 
Сканер находит ошибки, которые ИИ-инструменты (Cursor, Lovable, Bolt) оставляют в коде: 
утечки ключей API, открытый CORS, уязвимые зависимости и другое.

## Что внутри
`rules.js` — массив `window.CodeScanRules`. 31 проверка (секреты, доступ, инфраструктура, гигиена).

## Как использовать
Файл подключается на сайте `kodscan.ru` перед `scanner.js`. 
Если хочешь предложить новое правило или сообщить о ложном срабатывании — создай Issue.
